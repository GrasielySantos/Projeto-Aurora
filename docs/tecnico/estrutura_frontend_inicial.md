# 🌅 Estrutura Front-end Inicial — Projeto Aurora

## Objetivo

Definir a estrutura inicial do desenvolvimento da interface do Aurora.

A primeira versão será construída com tecnologias fundamentais da web, permitindo validar a experiência do usuário antes de evoluir para arquiteturas mais complexas.

---

# Tecnologias iniciais

## HTML

Responsável pela estrutura das páginas.

Utilização:

- Criar elementos da interface.
- Organizar conteúdos.
- Estruturar telas.

---

## CSS

Responsável pelo estilo visual.

Utilização:

- Aplicar identidade visual Aurora.
- Criar layouts.
- Definir cores, fontes e espaçamentos.

---

## JavaScript

Responsável pelas interações.

Utilização:

- Controlar ações do usuário.
- Criar comportamentos da interface.
- Implementar lógica inicial.

# Primeira etapa de desenvolvimento

A primeira tela será:

## Tela de Boas-vindas

Objetivo:

Apresentar o Aurora ao usuário e criar uma primeira experiência acolhedora.

Elementos:

- Logo.
- Nome Aurora.
- Mensagem inicial.
- Botão para iniciar jornada.
- Botão de acesso.

---

# Próximas evoluções

Após validar a primeira interface:

- Criar cadastro inicial.
- Criar dashboard.
- Implementar registros de sintomas.
- Integrar banco de dados.
- Evoluir para framework moderno.

# Princípios de desenvolvimento

O front-end deve seguir:

✅ Boa acessibilidade.
