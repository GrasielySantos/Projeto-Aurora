# Stack de Tecnologias — Projeto Aurora

## Objetivo

Definir as tecnologias que serão utilizadas no desenvolvimento do Aurora, considerando a construção de uma aplicação funcional, segura e adequada para evolução futura.

As escolhas serão feitas considerando aprendizado, boas práticas de desenvolvimento e criação de um projeto real para portfólio.

---

# Front-end

## Tecnologia inicial:

### HTML

Responsável pela estrutura das páginas e componentes da aplicação.

---

### CSS

Responsável pela estilização, layout e experiência visual do usuário.

---

### JavaScript

Responsável pela lógica da aplicação e interações do usuário.

---

## Possível evolução:

### React

Poderá ser utilizado futuramente para criação de uma interface mais dinâmica e organizada através de componentes.

---

# Back-end

## Tecnologia:

### Node.js

Responsável pela execução do JavaScript no servidor.

Utilizado para criar a lógica da aplicação e comunicação entre interface e banco de dados.

---

### Express

Framework utilizado para criação de APIs e gerenciamento das rotas da aplicação.

Responsabilidades:

- Receber informações do usuário.
- Processar dados.
- Comunicar com o banco de dados.

---

# Banco de Dados

## Tecnologia inicial:

### Firebase

Possível utilização para:

- Autenticação de usuários.
- Armazenamento de dados.
- Gerenciamento inicial da aplicação.

Motivo da escolha:

Facilitar o desenvolvimento inicial do MVP e permitir evolução gradual do projeto.

---

## Possível evolução:

Banco de dados estruturado conforme crescimento da aplicação.

Exemplos:

- PostgreSQL.
- MongoDB.

---

Utilizados para:
