#  User Flow Completo — Projeto Aurora

## Objetivo

Representar o caminho percorrido pelo usuário dentro do Aurora, desde o primeiro acesso até o acompanhamento contínuo da sua jornada.

---

# 1. Primeiro acesso

Usuário abre o Aurora.

⬇️

Tela de boas-vindas.

⬇️

Mensagem de acolhimento.

⬇️

Usuário escolhe:

- Continuar com Google.
- Entrar com e-mail.
- Criar conta.

---

# 2. Primeiro cadastro

Após criar a conta:

⬇️

Perfil inicial.

Usuário informa:

- Nome.
- Idade.
- Condição acompanhada.
- Situação do diagnóstico.
- Uso de medicamentos.
- Acompanhamento médico.

⬇️

Conta personalizada criada.

---

# 3. Entrada na Dashboard

Usuário acessa:

🏠 Início

Visualiza:

- Saudação personalizada.
- Como estou me sentindo hoje?
- Próximos compromissos.
- Atalhos rápidos.

---

# 4. Registro diário

Usuário seleciona:

➕

Registrar como estou hoje.

⬇️

Seleciona sintomas.

⬇️

Define intensidade.

⬇️

Adiciona observações.

⬇️

Salva registro.

---

# 5. Organização da rotina

Usuário pode acessar:

## 💊 Medicamentos

Cadastrar e acompanhar horários.

---

## 📅 Agenda

Registrar:

- Consultas.
- Exames.

---

## 📖 Minha Jornada

Visualizar:

- Sintomas.
- Exames.
- Consultas.
- Internações.
- Eventos importantes.

---

# 6. Preparação para consulta

Usuário seleciona período.

⬇️

Gera resumo:

- Sintomas.
- Eventos.
- Observações.
- Perguntas.

⬇️

Utiliza como apoio durante consulta.

---

# 7. Uso contínuo

O Aurora acompanha a jornada do usuário através de:

- Registros diários.
- Histórico.
- Organização de informações.
- Preparação para consultas.

---

# Princípios da experiência

O usuário deve sentir:

💙 Que possui controle sobre sua jornada.

💙 Que suas informações estão organizadas.

💙 Que não precisa depender apenas da memória.

💙 Que existe uma ferramenta criada para apoiar sua rotina.
