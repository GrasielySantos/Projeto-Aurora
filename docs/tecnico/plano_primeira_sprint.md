# 🌅 Plano da Primeira Sprint — Projeto Aurora

## Objetivo

Criar a primeira versão funcional da base do Aurora.

A primeira sprint tem como objetivo iniciar a interface do usuário e validar o fluxo principal da aplicação.

---

# Funcionalidades da Sprint

## Tela de Boas-vindas

Criar uma apresentação inicial do Aurora.

Elementos:

- Identidade visual.
- Mensagem de acolhimento.
- Botões de acesso.

---

## Cadastro inicial

Criar formulário para coleta das primeiras informações:

- Nome.
- Idade.
- Diagnóstico.
- Acompanhamento médico.
- Medicamentos.

---

## Dashboard inicial

Criar a tela principal após cadastro.

Exibir:

- Nome do usuário.
- Acesso aos registros.
- Registro de sintomas.
- Linha do tempo.

---

# Tecnologias iniciais

Front-end:

- HTML.
- CSS.
- JavaScript.

---

# Resultado esperado

Ao final da sprint, o usuário deverá conseguir visualizar o fluxo inicial do Aurora.
