#  Configuração Inicial de Desenvolvimento — Projeto Aurora

## Objetivo

Documentar as configurações iniciais necessárias para preparar o ambiente de desenvolvimento do Aurora.

Este documento serve como guia para organizar as ferramentas, tecnologias e primeiros passos antes da implementação do sistema.

---

# Ferramentas necessárias

## Editor de código

Ferramenta recomendada:

- Visual Studio Code

Utilização:

- Criar e editar códigos.
- Organizar arquivos do projeto.
- Gerenciar o desenvolvimento.

---

## Controle de versão

Ferramentas:

- Git
- GitHub

Utilização:

- Controlar alterações.
- Manter histórico do projeto.
- Compartilhar e apresentar o projeto como portfólio.

---

## Ambiente JavaScript

Ferramenta:

- Node.js

Utilização:

- Executar aplicações JavaScript.
- Gerenciar dependências.
- Criar ambiente de desenvolvimento.

---

# Estrutura inicial do projeto

O Aurora será organizado inicialmente em:

Projeto-Aurora/
├── frontend/ ├── backend/ ├── database/ ├── docs/ └── assets/


---

# Primeira fase de desenvolvimento

## Front-end

Responsável pela interface do usuário.

Inicialmente:

- Criar estrutura das telas.
- Desenvolver componentes.
- Aplicar estilos.
- Implementar navegação.

---

## Back-end

Responsável pela lógica do sistema.

Futuramente:

- Criar APIs.
- Gerenciar autenticação.
- Processar informações.
- Integrar com banco de dados.

---

## Banco de dados

Responsável pelo armazenamento das informações.

Inicialmente:

- Usuários.
- Sintomas registrados.
- Medicamentos.
- Consultas.
- Exames.
- Linha do tempo.

---

# Boas práticas

O desenvolvimento seguirá:
