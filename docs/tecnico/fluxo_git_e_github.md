# 🌅 Fluxo Git e GitHub — Projeto Aurora

## Objetivo

Definir o fluxo de versionamento do Projeto Aurora utilizando Git e GitHub.

---

# Conceitos utilizados

## Git

Ferramenta responsável por controlar alterações no projeto.

Permite:

- Criar histórico.
- Recuperar versões anteriores.
- Organizar mudanças.

---

## GitHub

Plataforma utilizada para:

- Hospedar o código.
- Apresentar o projeto.
- Construir portfólio.

---

# Fluxo inicial

## 1. Alteração

Criar ou modificar arquivos do projeto.

⬇️

## 2. Commit

Registrar uma mudança.

Exemplo:

"Adiciona documentação inicial"

⬇️

## 3. Push

Enviar alterações para o GitHub.

---

# Organização dos commits

Os commits devem ser claros.

Exemplos:

✅ "Adiciona tela de login"

✅ "Cria estrutura inicial do banco"

✅ "Atualiza documentação"

Evitar:

❌ "mudanças"

❌ "teste"

---

# Branch principal

Inicialmente:

main

Representa a versão principal do projeto.

---

# Boas práticas

- Fazer pequenos commits.
- Escrever mensagens claras.
- Atualizar documentação.
- Não enviar informações sensíveis.
