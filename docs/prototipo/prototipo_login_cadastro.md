# 🌅 Protótipo da Tela de Login/Cadastro — Projeto Aurora

## Objetivo da tela

Permitir que o usuário acesse o Aurora de forma simples e segura, mantendo seus registros pessoais protegidos.

A experiência deve transmitir confiança sem criar barreiras.

---

# Estrutura da tela

## 1. Identidade visual

Elementos:

- Logo Aurora.
- Fundo seguindo o Design System.
- Elementos visuais leves.

---

# 2. Mensagem principal

Sugestão:

"Vamos continuar sua jornada"

ou

"Entre para cuidar melhor da sua história."

---

# 3. Opções de acesso

## Continuar com Google

Objetivo:

Permitir acesso rápido utilizando uma conta Google.

Benefícios:

- Menos etapas.
- Não exige criação de nova senha.
- Facilita acesso ao aplicativo.

---

## Entrar com e-mail

Campos:

- E-mail.
- Senha.

Ações:

- Entrar.
- Recuperar senha.

---

## Criar conta

Para novos usuários.

Direcionamento:

Cadastro inicial do perfil.

---

# 4. Informações de privacidade

Mensagem de confiança:

"Suas informações pertencem a você. O Aurora utiliza seus dados apenas para organizar sua jornada de acompanhamento."

---

# 5. Botões

## Botão principal:

"Continuar"

## Botão secundário:

"Voltar"

---

# 6. Experiência desejada

O usuário deve sentir:

💙 Segurança.

💙 Facilidade.

💙 Confiança.

💙 Controle sobre seus dados.
